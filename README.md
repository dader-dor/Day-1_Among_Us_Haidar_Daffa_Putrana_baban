1. TIK Mengajar: Kurikulum Merdeka di Perguruan Tinggi

Materi ini membahas kebijakan Merdeka Belajar – Kampus Merdeka (MBKM), yaitu program yang memberikan kesempatan kepada mahasiswa untuk mengembangkan kompetensi melalui berbagai kegiatan pembelajaran di dalam maupun di luar kampus.

Pokok pembahasan:

MBKM: Memberikan kesempatan kepada mahasiswa untuk memperoleh pengalaman belajar di luar program studi melalui berbagai kegiatan pembelajaran.

MSIB: Program Magang dan Studi Independen Bersertifikat yang memberikan pengalaman belajar bersama mitra industri.

Delapan Bentuk Kegiatan MBKM: Pertukaran pelajar, magang atau praktik kerja, asistensi mengajar, penelitian, proyek kemanusiaan, kegiatan wirausaha, proyek independen, dan membangun desa atau KKN.

Metode Pembelajaran: Project-Based Learning (PjBL), Problem-Based Learning (PBL), dan Case-Based Learning (CBL).

Poin penting yang dipelajari:

MBKM dan MSIB memberikan kesempatan bagi mahasiswa untuk mengembangkan keterampilan, memperoleh pengalaman industri, membangun jejaring profesional, serta meningkatkan kesiapan menghadapi dunia kerja.

2. Pengenalan Akademik Jurusan TIK

Materi ini membahas visi, misi, dan rencana strategis Jurusan Teknik Informatika dan Komputer (JTIK) Politeknik Negeri Jakarta periode 2026–2030.

Pokok pembahasan:

Visi JTIK: Menjadi jurusan bertaraf internasional untuk mendukung daya saing bangsa dalam bidang informatika dan komputer.

Misi Pendidikan Vokasi: Menyelenggarakan pendidikan berbasis ilmu pengetahuan, teknologi, rekayasa, dan seni.

Riset dan Inovasi: Mengembangkan penelitian serta produk inovasi di bidang informatika dan komputer.

Tata Kelola Digital: Mengembangkan pengelolaan jurusan yang efisien dan akuntabel berbasis teknologi informasi.

Terdapat lima fokus pengembangan JTIK, yaitu penguatan internal jurusan, kerja sama institusi dan industri, pengembangan sumber daya manusia, peningkatan sarana dan prasarana, serta pengembangan inkubator bisnis TIK.

Poin penting yang dipelajari:

Sebagai mahasiswa Teknik Multimedia dan Jaringan, penting untuk mengembangkan kompetensi teknologi, mengikuti perkembangan industri, serta memanfaatkan fasilitas dan peluang kolaborasi yang disediakan oleh jurusan.

3. Building with AI: Prompt Engineering

Prompt engineering merupakan teknik menyusun instruksi kepada Artificial Intelligence (AI) agar menghasilkan jawaban yang tepat, relevan, dan sesuai kebutuhan.

Struktur prompt yang baik:

Role: Menentukan peran AI.

Task: Menjelaskan tugas yang harus dilakukan.

Context: Memberikan informasi pendukung.

Format: Menentukan bentuk hasil yang diinginkan.

Pemberian instruksi dan konteks yang jelas dapat meningkatkan kualitas hasil AI, mengurangi kesalahan respons, serta memberikan kontrol yang lebih baik terhadap hasil yang dihasilkan.

4. Pengenalan Git dan GitHub

Git merupakan sistem version control yang digunakan untuk melacak dan mengelola perubahan pada file atau proyek. Sementara itu, GitHub adalah platform berbasis web untuk menyimpan repository Git secara online dan mendukung kolaborasi.

Konsep penting Git:

Repository: Tempat penyimpanan proyek beserta riwayat perubahannya.

Commit: Catatan penyimpanan perubahan pada proyek.

Branch: Cabang pengembangan untuk mengerjakan perubahan secara terpisah.

Pull Request: Mekanisme untuk mengajukan dan meninjau perubahan sebelum digabungkan.

Version Control: Sistem untuk melacak dan mengelola riwayat perubahan proyek.

Dalam Git terdapat tiga komponen utama, yaitu Working Directory, Staging Area, dan Git Directory yang berperan dalam proses pengelolaan perubahan file.
